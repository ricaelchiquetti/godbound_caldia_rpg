
## Exemplos de Problemas de Facção

Cada Problema que uma facção possui deve ser a semente para uma aventura. Toda aflição que incomoda um grupo deve ter espaço para o envolvimento dos PJs, seja como uma fonte de ajuda ou como um ponto fraco na armadura de uma facção inimiga. Os Problemas ajudam a dar cor e sabor aos percalços de uma facção, mas seu valor real para você, como Mestre, é como um gancho de aventura fácil.

Os Problemas listados aqui são apenas uma breve seleção das possibilidades. Quando possível, você deve personalizá-los e dar-lhes um rosto no qual os PJs possam se concentrar. Se você tem um grupo de bandidos atormentando uma vila, dedique algumas palavras sobre o chefe dos bandidos que os lidera. Se você tem um bando infame de "reformadores" religiosos sinistros minando o templo principal de uma cidade, dê ao líder um nome e uma descrição. Se os PJs decidirem ir atrás do Problema, fica mais fácil direcionar o foco deles, e mesmo que não o façam, isso ajuda a dar um nome a quem atribuir os eventos recentes.

Se parecer que os PJs vão acabar se confrontando diretamente com um Problema, talvez você queira reservar um pouco de tempo para preparar algumas estatísticas para ele — seja na forma de fichas de combate para a liderança e capangas, uma mini-dungeon de algum quartel-general importante que eles utilizem ou um desafio de Corte para um problema mais político. Dessa forma, se os PJs resolverem lidar com o problema de maneira mais pessoal, você não precisará pausar o jogo para fabricar os detalhes na hora.

Geralmente, leva cerca de uma sessão de jogo para resolver um ponto de Problema. Se a dificuldade estiver muito abaixo da escala dos PJs, como um chefe de bandidos contra um panteão de Godbound, eles podem conseguir extingui-lo completamente em apenas algumas cenas. Mesmo problemas muito maiores podem ser resolvidos rapidamente se os PJs conseguirem descobrir quem é o responsável por eles e, em seguida, lidarem com a situação no estilo pelo qual os personagens jogadores são famosos.
