
## Objetivos de Facção

Facções controladas por PdMs agirão de acordo com seus objetivos. Se suas ambições não forem óbvias, o Mestre pode escolher ou rolar nas tabelas de objetivos de facção abaixo, usando qualquer modelo de comportamento que melhor se adapte à facção.

### Tabela d10: Tiranos Despóticos

| d10 | Objetivo |
| :---: | :--- |
| **1–2** | Promover uma mudança dedicada unicamente a glorificar o tirano, que seja totalmente inútil como Atributo. |
| **3–4** | Infligir uma derrota militar a um rival incômodo, causando pelo menos um ponto de dano à Coesão ou infligindo um ponto de Problema. |
| **5–6** | Eliminar um ponto de Problema relacionado à resistência ao governo do dspot. |
| **7–8** | Promover uma mudança para criar um Atributo que seja excepcionalmente útil para erradicar dissidentes internos. |
| **9–10** | Expandir o alcance da facção, seja anexando terras não reivindicadas como uma mudança Improvável ou capturando um inimigo. |

### Tabela d10: Conquistadores Marciais

| d10 | Objetivo |
| :---: | :--- |
| **1–2** | Esmagar um rival menor e mais fraco, transformando-o em um estado tributário submisso ou em uma pilha de escombros fumegantes. |
| **3–4** | Construir ou expandir um Atributo militar, projetado para ameaçar um rival vizinho específico. |
| **5–6** | Acumular metade do Interesse máximo possível no rival que eles têm mais probabilidade de invadir a seguir. |
| **7–8** | Resolver um ponto de Problemas relacionado a dificuldades militares ou ineficiências no estado. |
| **9–10** | Usar um Atributo não militar para Coagir um Rival (*Coerce a Rival*) a perder um de seus Atributos militares. |

### Tabela d10: Sobreviventes Egocêntricos

| d10 | Objetivo |
| :---: | :--- |
| **1–2** | Não realizar ações externas pelo maior tempo possível, pelo menos até ser alvo de uma ação de Coagir um Rival por parte de um inimigo. |
| **3–4** | Resolver um ponto de Problemas, priorizando aqueles relacionados a envolvimentos externos. |
| **5–6** | Promover uma Mudança para criar um Atributo que seja útil para manter sua sobrevivência contra potências externas. |
| **7–8** | Estocar Domínio para uso futuro, acumulando o dobro de pontos em relação ao Poder da facção. |
| **9–10** | Coagir um Rival com um Atributo não militar em uma tentativa de negar-lhe alguma ambição externa sem derramamento de sangue. |

### Tabela d10: Manipuladores Maquiavélicos

| d10 | Objetivo |
| :---: | :--- |
| **1–2** | Criar o máximo de Interesse possível no rival ou ameaça estrangeira mais provável. |
| **3–4** | Aumentar os Problemas de um rival em pelo menos um ponto usando Atributos não ostensivos para fazê-lo. |
| **5–6** | Convencer outra facção a agir em seu favor por meio de ameaças ou oferecendo ações de Ajudar um Aliado. |
| **7–8** | Promover uma Mudança para criar um Atributo que pareça inofensivo, mas que será usado para fins de autoengrandecimento. |
| **9–10** | Diminuir um Problema por meio de um Atributo não militar, resolvendo-o através de alguma trama astuta. |
