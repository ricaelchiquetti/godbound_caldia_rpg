# Caldia - RPG Landing Page (React)

Este é um projeto React (criado com Vite) para o compêndio de Caldia.

## Como rodar localmente (para desenvolvimento)

1. Instale o Node.js no seu computador.
2. Abra o terminal nesta pasta e rode:
   `npm install`
3. Para iniciar o servidor de desenvolvimento:
   `npm run dev`

## Como publicar no GitHub Pages

Para que os jogadores acessem via link, siga estes passos:

1. Faça o upload deste projeto para o GitHub.
2. No seu terminal, rode `npm run build`. 
3. Isso vai gerar uma pasta chamada `dist`.
4. Você pode configurar o GitHub pages para ler a branch gh-pages ou fazer o upload do conteúdo da pasta `dist` diretamente para um servidor.

Dica: No arquivo `src/data/worldData.js` você pode adicionar todas as cidades e o restante dos Deuses facilmente!
